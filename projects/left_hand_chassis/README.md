# 左手底盘控制 · 独立电脑端 v1.0

本项目实现左手手势到前后/旋转控制意图的独立模块，含摄像头预览、每次启动校准、虚拟底盘和数值日志。当前阶段在电脑端验证操作，不连接机器人。

## 开始使用

完整解压本目录，双击 **`run_pc.cmd`**。首次会建立项目独立 Python 环境并安装固定版本依赖，需要联网；已有环境完整时直接启动。支持64位 Python 3.10～3.12，可自动找到已有 `robot_vision` Python；不会向它安装或覆盖依赖。

已知可用的独立环境也可用环境变量 `LEFT_HAND_PYTHON` 指向其 Python，或将完整Python路径写到本地 `.local-python.txt` 的第一行；仅在全部依赖版本匹配时只读复用。本地路径文件不提交、不随发布包分发。

1. 点击“打开摄像头”，让**自己的左手**完整入镜，掌面朝向镜头。画面已镜像，骨架旁显示 `Left`。右手不参与控制；驱动本身镜像导致左右错误时，先关闭输入，切换“交换左右手标签”，再重新打开并校准。
2. 点击 **①校准静止位**。3秒准备后稳定保持约1秒，建议自然半握。此时的手指姿态和手掌倾角分别作为静止参照和旋转零点。
3. 点击 **②采集握拳**，五指收紧，拇指也收拢。保持与静止位相近的手掌倾角；同样3秒准备、约1秒采样。
4. 点击 **③采集展开**，五指完全伸展。程序检查三种手势是否能区分，失败会提示重采。静止位不能与握拳或完全展开重合，否则同一姿态会有两种含义。
5. 点击“启用控制预览”，先回到静止位，稳定0.4秒后进入 ON。
6. 握拳前进，五指展开后退；回到自然静止手势或其他过渡手势，前后输出清零。手掌向画面左侧倾斜时左转，向右侧倾斜时右转。可以一边握拳前进，一边倾斜转弯。

旋转以每次校准角度为零点，默认±10°死区，偏转40°达到所选最大强度。强度是归一化软件控制量，**不是米/秒或度/秒**。虚拟底盘轨迹只展示方向。

空格、Esc或“暂停”清零两种输出；丢手、低置信度、旧采样超过300ms、窗口失焦、过度倾斜也会暂停。恢复后需手动启用并回到静止位。更换输入、左右标签或关闭相机后，本次校准失效；程序不自动加载历史校准。

**`run_demo.cmd`** 展示合成的前进、后退和左右转，用于查看界面与程序链路；演示不代表真人识别效果。

## 文件与日志

- `left_hand_drive/core.py`：纯 Python 几何、三姿态校准、控制状态机，可独立导入。
- `capture.py`：OpenCV + MediaPipe Hands 21点识别；单线程持有摄像头，只保留最新采样。
- `gui.py`：中文单窗口、校准操作、虚拟底盘。
- `runtime/latest_command.json`：最新软件目标快照，约20Hz更新；退出会写零输出。该目录不提交 GitHub。
- `logs/runs/<来源-时间>/`：运行元数据、约10Hz数值CSV、事件JSONL、本次校准记录。默认不保存照片或视频。
- `logs/development/`、`logs/verification/`：开发说明与实际验证结果。

在 Git 克隆的 `luxinruui/aic--` 仓库内，运行后双击 `sync_logs.cmd` 可提交并推送本子项目日志。它只处理日志文本，不提交其他代码或媒体，不强制推送；Git需要已登录且允许推送。ZIP副本仍可运行、保存日志，但不能直接推送；需要先克隆仓库。仓库当前为公开仓库，推送的数值和事件日志也会公开。

## 后续接入接口

见 [接口说明](docs/INTEGRATION.md)。输出 `forward` 与 `yaw_left`，范围均为[-1,1]；正数分别为前进和左转，负数分别为后退和右转。本项目不含舵机控制、机器人TCP发送或串口驱动。

## 验证命令

在本项目目录执行（Windows可将 `python` 换为 `.venv\Scripts\python.exe`）：

```sh
python -m unittest discover -s tests -v
python -m left_hand_drive --check
python -m left_hand_drive --headless --demo
python scripts/gui_smoke.py
```

识别使用 MediaPipe 0.10.21 的 `solutions.hands`，模型随wheel提供，本地CPU运行。首次安装及具体真人效果分别见启动日志和验证说明。
