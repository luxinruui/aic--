接收端重新启动、机器人断电或位置被其他程序改变时，先确认以下基准。左右按机器人自身方向：双肘伸直、双肩侧平举、双大臂向两侧展开。

| 大臂 | 3 = 2256 | 33 = 2224 |
| 肩 | 4 = 1569 | 34 = 2040 |
| 固定槽 | 2 = 2048 | 32 = 2048 |

设置基准时先暂停电脑并正常停止本接收端，避免和原动作编辑器同时控制。基准设置完成、退出原控制程序后，在NoMachine的Linux终端运行：

```sh
cd /home/bcsh/Desktop/aic_dual_hand_robot_20261117
sh start_robot.sh --confirm-arm-baseline
```

现场终端已运行上面的已确认基准服务，正常使用时保持该窗口开启。以后需要重启时，先Ctrl+C正常退出；确认参数表示人已经核对基准，并非舵机位置回读。

若首次姿态不清楚，可在接收端正常停止、UART空闲且人已确认双臂活动空间后，明确执行一次 `python3 initialize_arms.py --move`，等待5秒并观察基准是否到位，再启动接收端。不带`--move`只检查、不打开UART。就位指令提交后没有已验证的立即取消命令，可能继续最多5秒，异常需用机器人电源停止；本工具不在每次启用时自动运行。

只看软件预览时，先正常停止实机接收端，再运行 `sh start_preview.sh`。不要同时启动旧底盘接收端、原六轴接收端或巡线程序占用同一个UART。

## 2. 电脑端

1. 双击桌面 **启动双手机器人.cmd**。若现有联控窗口仍打开，直接使用它，避免多开相机。也可进入电脑目录双击 `run_robot.cmd`，在“连接背包…”填 `172.20.10.3`、`8770`。
2. 背包重启后，在电脑“连接背包…”里手动重新连接，确认显示“实机 · DISARMED”。不自动重连或恢复ON。
3. 打开摄像头0，确认绿骨架Left为自己的左手、蓝骨架Right为右手。双手保持完整出镜、掌面朝镜头。
4. 分别完成右手①起始位、②握拳、③展开，以及左手①静止位、②握拳、③展开。每项按界面倒计时保持稳定；自然半握不能与握拳或展开重合。
5. 首次建议选择“仅上肢”，在“范围…”里只启用左肘、范围0～20°，先验证食指方向。再逐项增加关节，最后选择“双手联合”。切换模式和范围后需要重新手动启用。
6. 点击“启用所选模式”，所需手部保持任意有效姿势入镜即可到ON，不需再回半握/展开，也不需保持匹配0.4/0.5秒。首帧维持软件参考，随后缓慢跟随手势；右上角“上肢已下发N段”是背包发送计数，不是舵机到位反馈。
7. **空格、Esc或暂停按钮统一暂停**。丢手、失焦、过时数据、断网会暂停；恢复后需手动重新启用。

左手握拳前进、展开后退、左右倾斜转向；前后和转向可同时输出。右手拇指联动双大臂，食指控制左肘、中指左肩、无名指右肩、小指右肘。
