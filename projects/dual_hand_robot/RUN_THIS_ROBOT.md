## 2. 电脑端

1. 双击桌面 **启动双手机器人.cmd**。若现有联控窗口仍打开，直接使用它，避免多开相机。也可进入电脑目录双击 `run_robot.cmd`，在“连接背包…”填 `172.20.10.3`、`8770`。
2. 背包重启后，在电脑“连接背包…”里手动重新连接，确认显示“实机 · DISARMED”。不自动重连或恢复ON。
3. 打开摄像头0，确认绿骨架Left为自己的左手、蓝骨架Right为右手。双手保持完整出镜、掌面朝镜头。
4. 分别完成右手①起始位、②握拳、③展开，以及左手①静止位、②握拳、③展开。每项按界面倒计时保持稳定；自然半握不能与握拳或展开重合。
5. 首次建议选择“仅上肢”，在“范围…”里只启用左肘、范围0～20°，先验证食指方向。再逐项增加关节，最后选择“双手联合”。切换模式和范围后需要重新手动启用。
6. 点击“启用所选模式”。左手回到本次半握静止位；右手按底部提示匹配背包的软件参考，首次基准通常为五指展开，稳定约0.5秒。显示ON/活动状态后再做运动手势。
7. **空格、Esc或暂停按钮统一暂停**。丢手、失焦、过时数据、断网会暂停；恢复后需手动重新启用。

左手握拳前进、展开后退、左右倾斜转向；前后和转向可同时输出。右手拇指联动双大臂，食指控制左肘、中指左肩、无名指右肩、小指右肘。
